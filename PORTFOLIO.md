# Forma — opis do portfolio

## Krótki opis

Responsywna strona demonstracyjna fikcyjnego salonu fryzjerskiego. Przedstawia ofertę, przykładowy cennik, zespół, galerię inspiracji i dane kontaktowe. Powstała w HTML, CSS i JavaScript, bez frameworka i bez dodatkowych bibliotek.

## Cel

Ułatwić odwiedzającemu poznanie salonu, znalezienie ceny usługi i przejście do kontaktu. Wizualny kierunek to ciepła biel, zieleń, duże nagłówki i delikatnie zaokrąglone zdjęcia oraz przyciski.

## Rozwiązania, które warto pokazać

- Układ dopasowany do komputerów, tabletów i telefonów przez CSS Grid, Flexbox i media queries.
- Menu mobilne obsługujące kliknięcie, Escape, zmianę szerokości okna i zamknięcie po wybraniu sekcji.
- Nawigacja dostępna także bez JavaScriptu, widoczny fokus klawiatury i link pozwalający pominąć menu.
- Czytelna struktura HTML: sekcje, nagłówki, profile zespołu, zdjęcia z podpisami i lista godzin otwarcia.
- Odroczone pobieranie zdjęć niżej na stronie oraz wspólne kolory zapisane w zmiennych CSS.

## Uczciwe przedstawienie projektu

To projekt koncepcyjny, nie zlecenie dla rzeczywistej firmy. Salon, osoby, ceny i dane kontaktowe są przykładowe. Zdjęcia przedstawiają inspiracje, nie wykonane usługi. Przyciski prowadzą do kontaktu; strona nie wysyła wiadomości ani nie rezerwuje wizyt.

Projekt rozwijany z pomocą AI: propozycje i kod były omawiane etapami, z nauką HTML, CSS i JavaScript oraz poprawkami wyglądu na podstawie oceny autora. W portfolio należy opisać własny wkład zgodnie z faktycznym przebiegiem pracy.

## Przed publikacją

1. Potwierdzić autorów i warunki użycia zdjęć, przygotować docelowe pliki oraz pełne źródła wszystkich zdjęć.
2. Zapisać screeny: pierwszy ekran na komputerze, telefon z menu oraz usługi i kontakt.
3. Opublikować demo i dodać jego adres oraz link do repozytorium do portfolio.
4. Sprawdzić wersję opublikowaną także na prawdziwym telefonie.
